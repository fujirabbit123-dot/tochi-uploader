# プライバシーポリシー / Privacy Policy

最終更新日 / Last updated: 2026-11-20

## 1. このツールについて
tochi-uploader は、YouTubeチャンネル「土地の履歴書」の運営者本人だけが使う個人用の投稿ツールです。

## 2. 使う情報
YouTube Data API を通じて、運営者本人のチャンネルへの動画・サムネイルのアップロードと、動画情報（タイトル・説明・タグ・公開設定）の登録のみを行います。

## 3. 保存と共有
認証情報（トークン）は運営者本人のパソコンの中にだけ保存されます。取得した情報を第三者に提供・販売することはありません。

## 4. Google API の利用
本ツールによる Google API から受け取った情報の利用は、Google API Services User Data Policy（限定的使用の要件を含む）に従います。

## 5. 削除
アクセス許可は Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。

## English summary
tochi-uploader is a personal tool used only by the channel owner. It uses the YouTube Data API solely to upload videos and thumbnails to the owner's own channel. Tokens are stored only on the owner's computer. No data is shared with or sold to third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from the Google Account settings.
